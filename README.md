# Cursor_Rushi

## LTPI IP for Cyclone V FPGA

[`ltpi_cyclonev/`](ltpi_cyclonev/) contains a from-scratch, MIT-licensed
implementation of LTPI (LVDS Tunneling Protocol & Interface, the Open
Compute Project DC-SCM standard) for Intel/Altera Cyclone V FPGAs, along
with a self-checking Icarus Verilog simulation suite and an example Quartus
Prime project. See [`ltpi_cyclonev/README.md`](ltpi_cyclonev/README.md) for
details.
