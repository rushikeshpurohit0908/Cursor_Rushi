| Side | Content |
| --- | --- |
| **Front** | Altera logo · Space Expo · tagline **Accelerating Innovators** · supporting line on FPGA/SoC for aerospace, defense, and space |
| **Back** | Aerospace & Defense talking points (Adapt, SWaP, Secure, Agilex™) · CTA link |

## Preview locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

- Click the card (or press **Flip card**) to reverse it
- Use **Print / Save PDF** for a 5×7 dual-side handout layout
